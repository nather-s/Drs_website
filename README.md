# Dr. Shilpa Bansal Agrawal — clinic website

Redesign of drshilpagynaecologist.com for Harleys Women's Clinic, Andheri West.

Built with Next.js, Tailwind CSS v4, Motion, and a gauge adapted from bklit UI
(MIT; licence in `components/bklit`).

## Run locally

```bash
npm install
npm run dev
```

## Design preview export

```bash
npm run export:preview   # static copy in out/ with relative asset paths
```

## Status

UI redesign in progress. Placeholders still to replace: doctor portrait, clinic photos,
Google reviews feed, booking email and the assistant's calendar connection.
Clinic facts live in `lib/clinic.ts`.
